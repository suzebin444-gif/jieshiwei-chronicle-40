# 统一视觉圣经

## 画幅与风格

- 单页横版16:9，8K级细节目标。
- 中国古典水墨史诗感与电影级写实漫画结合。
- 纸张肌理、真实人物比例、自然光、海雾与沿海空气感。
- 主色：土黄、墨黑、青灰、海蓝；重要时刻可使用克制的暖金。
- 不使用现代影棚光、塑料质感、过度饱和、Q版比例或西式奇幻盔甲。

## 文字与标注

- 所有正文使用简体中文，必须逐字准确。
- 人名牌是独立矩形小框，紧靠对应人物，不加箭头。
- 人物对白尽量放在人物身旁，使用短箭头明确指向说话者。
- 旁白框、史料说明框、页码签不加箭头。
- 每页左下角固定页码签：`第X章·章节名｜第Y页`。
- 旗帜、城门、牌匾无明确要求时不放文字；必须放字时只出现指定词语。

## 连续性

- 同一人物跨页保持脸型、年龄、发须、衣甲与主色一致。
- 同一场景跨页保持城墙形制、港湾方向、玄武山轮廓和天气逻辑一致。
- 武器、船只、服饰、建筑和官制必须与对应时代相符。
- 五色狮造型必须以用户提供的原型照片为基础，保留五种主色、狮头纹样、灯彩结构与列阵关系，不可替换为普通南狮。

## 核心人物锚点

| 人物 | 视觉锚点 | 文字规则 |
|---|---|---|
| 花茂 | 红色官袍或黑色山纹甲、深红披风、长剑，沉稳刚烈 | 名牌写“花茂” |
| 朱元璋 | 明初帝王服制，威严克制 | 不使用戏曲夸张妆容 |
| 俞大猷 | 中老年、清瘦坚毅、抗倭将领气质 | “碣石卫”三字必须完整 |
| 伍端 | 山林义士形象，粗布甲胄、刚烈 | 只写“伍端”，禁止“吴段” |
| 苗之秀 | 清代将领服制，时代与官阶相符 | 不与明代甲胄混用 |
| 刘永福 | 晚清老将，沉着、久经战阵 | 官职与年代需复核 |

## 负面约束

- 禁止乱码、繁简混杂、错别字、额外水印和无关英文。
- 禁止名牌箭头、长箭头穿越画面、箭头指错人物。
- 禁止虚构大规模会战、具体战果或工程规模。
- 禁止把后世建筑、武器、服装或行政标志提前到历史场景。
