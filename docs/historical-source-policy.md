# 史实与资料规范

## 资料优先级

1. 《陆丰县志》《陆丰市志》及正式地方志资料。
2. 明清时期《惠州府志》等同期或接近同期的府县志、奏疏、档案。
3. 各级政府、文旅、文物、非物质文化遗产保护机构的正式资料。
4. 陆丰市政协文史资料和经过编校的地方史料。
5. 学术论文、专著和可信研究机构出版物。
6. 口述史和民间传说，只能作为氛围或叙事线索，并明确标注。
7. 网络百科仅用于发现线索，不能单独支撑关键史实。

## 每个场景最少记录

- 事件名称与时间范围。
- 地点与当时行政归属。
- 主要人物及可确认身份。
- 可核实事实、艺术化补充与待考内容分开书写。
- 至少一条来源；关键争议事实应有两条独立来源交叉印证。

## 创作边界

- 可以重构天气、镜头、无名群众动作和不改变结论的过场对白。
- 不得无依据补写人数、伤亡、舰船型号、火炮数量、工程尺寸、官职、战果或秘密计划。
- 对没有证据的大型战斗，改为戒备、巡防、传令、撤守、救护或民生影响。
- 明清易代、抗倭、鸦片战争、辛亥革命、农运、抗战等敏感历史节点，应把已证事实放在旁白中，人物对白保持克制。

## 史实状态字段

- `verified`：有可靠资料直接支持。
- `corroborated`：有两个以上来源相互印证。
- `inferred`：由资料合理推断，必须说明推断链。
- `legend`：民间传说，不作为确定事实陈述。
- `pending`：尚待核验，不进入最终旁白。
