## 完成度定义

| 层级 | 条件 |
|---|---|
| 规划完成 | 章节主题、年代、页数和主线已确定 |
| 提示词完成 | 有章节提示词或逐页提示词，且通过史实检查 |
| 图片找回 | 找到原图，但章页号可能仍待确认 |
| 正式页 | 章页号明确、版本登记、文字与画面人工通过 |
| 章节完成 | 该章所有计划页均为正式页 |

本项目只在满足最后一项时才将章节标为“图片完成”。
