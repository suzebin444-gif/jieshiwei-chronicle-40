# 文件命名与版本规范

## 正式页

`assets/pages/ch-XX/ch-XX_p-YYY_v-ZZ.webp`

- `XX`：两位章号。
- `YYY`：三位页号。
- `ZZ`：两位版本号。

## 候选素材

`assets/catalog/asset-NNNN.webp`

候选素材的原始文件名、生成标题和来源写入图片清单，不依赖文件名表达语义。

## 参考图

`assets/references/ref-主题-序号.扩展名`

参考图不得混入正式页目录；清单中需注明“仅供造型参考”及权利说明。

## 状态

- `needs_mapping`：已找回，尚未可靠对应章页。
- `needs_review`：章页已知，仍待文字与画面复核。
- `approved`：人工通过，可进入最终画廊。
- `superseded`：已被更高版本替换。
- `rejected`：明确不再使用，但保留审计记录。
