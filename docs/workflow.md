# 生产工作流

## 1. 史料卡

为每章建立事件卡：时间、地点、人物、可确认事实、争议点、主要来源和禁写项。没有通过史实检查的内容不得进入最终旁白。

## 2. 章节拆页

按“建立环境—推进冲突—历史节点—民众反应—章节收束”拆分页数。每页只承担一个核心叙事动作，避免把多个时代压在一张图中。

## 3. 生成提示词

拼接顺序：

1. `prompts/MASTER-PROMPT.md` 中的全局规则。
2. `prompts/chapters/ch-XX.md` 中的章节专用提示词。
3. 当前页的镜头、人物、动作、旁白、对白和页码签。
4. 与上一页连续性说明。

## 4. 生成与命名

- 初次生成：`ch-XX_p-YYY_v-01.webp`。
- 重绘递增版本号，不覆盖旧图。
- 候选图先进入 `assets/catalog/`，登记后再审核。

## 5. 五项审核

1. 史实：年代、人物、服制、武器、建筑、制度是否合理。
2. 文字：所有简体中文逐字检查。
3. 指向：只有对白箭头，且明确指向正确说话者。
4. 连续性：人物、场景、天气、光线和空间方向一致。
5. 构图：旁白不遮关键动作，页码签位置统一。

## 6. 入库与发布

更新图片清单，运行：

```bash
python3 scripts/validate_project.py
python3 scripts/build_site_data.py
```

通过校验后再提交。章节只有在计划页全部为 `approved` 时才能标记为图片完成。
