# 《碣石卫》50章历史漫画：第7—40章时间线规划与 Codex 生图提示词

## 一、续写原则

- 第1—6章保持现有成稿，不重新编号；第六章《砖石新城》结束于清康熙八年（1669年）。
- 废止“第七章回到1563年抗倭”的旧方案，避免与第三章《抗倭烽火》重复。
- 第7—40章严格沿时间顺序，从1669年写到2020年代—2026年。
- 第41—50章暂不确定标题、页数、专题与提示词；待第7—40章全部完成并修订后，再依据前40章实际内容统一设计。
- 史料明确的日期、人物、城制、兵额、炮台和行政建置可以写入旁白；无法核实的故事只能作为普通生活场景，不得伪装成史实。
- 人物对白属于漫画化转述，不使用引号冒充史书原话；重大史实优先放入“旁白框”。

## 二、所有章节共用的生图母提示词

将下面这段“母提示词”放在每一章专用提示词之前：

```text
你正在连续生成中文历史漫画《碣石卫》。每次只生成一页独立的16:9横版漫画图，禁止把多页拼在一张图中。画风固定为“中国古典水墨史诗＋电影级写实漫画分镜”：8K质感、宣纸肌理、干净细密墨线、真实人物比例、自然光、海雾云气、土黄/墨黑/青灰/海蓝/暖金主色。建筑、船只、兵器、服装、生产工具必须符合该页年代；禁止日漫大眼、Q版、奇幻、现代穿帮、英文、水印和乱码。

每页包含1—3个简体中文文字框。旁白框不画箭头；人物对白框尽量放在说话者身旁，用一根短而清晰的小箭头指向本人。每个说话人物的姓名牌必须紧贴对应人物，姓名、台词和箭头不得对换。文字必须逐字照抄，不得增删、改写、漏字或生成异体乱码。旗帜、城门、牌匾原则上不写字；如非写不可，必须在提示词中给出唯一的准确文字。

左下角统一页签：“第X章·章节名｜第Y页”。前后页必须保持人物面容、服装、城墙材质、港湾方向、玄武山轮廓、天气和光线连续。历史人物首次出现时建立固定形象，后续不得随意换脸。战斗场面保持庄重克制，不画血腥特写。

生成前先检查：年代是否正确、史实是否有依据、人物是否在正确阵营、旧土城与清代砖石新城是否混淆、对白箭头是否指向本人、姓名牌是否贴近本人、页签章名和页码是否正确。若无法确认史实，改用旁白中的审慎表述，不得自行补造数字、官职、战果、项目容量或投产日期。
```

## 四、第7—40章 Codex 章节专用提示词

使用方法：每次先发送“生图母提示词”，再发送对应章节的专用提示词。Codex应先按本章页数编排逐页文字，再一页一页生图。

### 第7章《海疆新制》｜1669—1683｜10页

```text
生成第7章《海疆新制》，共10页。承接第六章清代砖石新城落成，从1669年碣石卫改称碣石镇写起。以驻镇总兵、左中右三营、额定官兵3575名和兵船60只为史实主轴，依次表现新城接防、营伍编制、兵船点验、军械仓、湾内巡哨、陆海联防与百姓重新获得安全感。数字只放旁白，不让人物口头背诵。苗之秀沿用第六章固定形象；结尾为晨雾中水师船队驶出碣石湾。页签统一“第七章·海疆新制｜第X页”。
```

### 第8章《展界归潮》｜1669—1700｜10页

```text
生成第8章《展界归潮》，共10页。重点写展界后的普通百姓，而不是重复筑城：流离居民携家返回、辨认旧屋、修复渔船、重开盐田、恢复码头和市集、军民重新分工。画面从荒凉冷灰逐页转为有炊烟的暖色。不得把“展界”画成一次盛大庆典，也不得弱化迁界造成的创伤。结尾为归航渔船与新石城同框。页签统一“第八章·展界归潮｜第X页”。
```

## 六、史实校验与禁用规则

1. 第7章必须从1669年开始，不再回到1563年；俞大猷抗倭内容已在第三章完成。
2. “碣石卫”是明代卫所名称；清康熙初改称“碣石镇”。清代页面若写“卫”，只能用于回忆旧城。
3. 1717年浅澳炮台主要为防海盗；1839年才进入禁烟与防英军的叙事，两个目的不得混写。
4. 林则徐与刘永福的碣石活动均以地方史料为依据，不杜撰他们长期居住碣石或亲自参加不存在的大战。
5. 1911年辛亥光复与1927年红二师围攻是两次不同事件，人物、旗帜、服装和政治背景不得混淆。
6. 1941年日军登陆时间与部队番号可写旁白；不得把侵略军画成正面英雄。
7. 1949年8月16日是陆丰县城解放节点，10月26日为全境解放节点，不合并成同一天。
8. 当代能源、风电、核电与海工项目只使用政府或央企公开信息，不凭空填写容量、投资、产值和投产日期。
9. 五色狮必须以用户照片为原型；没有照片参考时不生成该章正式页面。
10. 所有人物台词贴近本人并用小箭头对应；旁白没有箭头；姓名牌始终贴近对应人物。
